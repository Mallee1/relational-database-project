# Garden Glory Data Warehouse & SQL Analytics Project

## Overview
This project demonstrates end-to-end database design, data warehousing, SQL analytics, and business intelligence concepts using the Garden Glory case study.

## Key Features
- Relational database design and data modeling
- Star schema with fact and dimension tables
- SQL queries with joins, grouping, and aggregation
- SQL view for reusable reporting
- Business intelligence analysis using Excel
- Market basket analysis and basic predictive modeling concepts

## Data Architecture
This project includes both:
- a source transactional database
- a dimensional data warehouse database

### Fact Table
- SERVICE_HOURS

### Dimension Tables
- TIMELINE
- PROPERTY
- EMPLOYEE

## SQL Components
- Insert statements for PROPERTY_SERVICE records
- Table creation scripts for the star schema
- Aggregate reporting query
- SQL view for total hours worked

## Analytics & BI
- Excel pivot table analysis
- Market basket analysis
- Decision tree concept for predicting repeat customers

## Technologies Used
- SQL
- Microsoft Access
- Excel
- Data warehousing concepts
- Business intelligence techniques
